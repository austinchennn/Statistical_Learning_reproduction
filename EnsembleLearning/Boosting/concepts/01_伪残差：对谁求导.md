# 伪残差：到底对谁求导？

> 我当时的卡点：线性模型 $\hat y = Wx$ 我会求导（对 $W$），但 GBDT 的 $g_i = \partial L / \partial \hat y_i$ 我理解不了——这是公式求导还是数值计算？

## 1. 关键：求导对象变了

| | 线性模型 / 神经网络 | GBDT |
|---|---|---|
| 要更新什么 | 参数 $W$ | **整个预测值** $\hat y$（函数空间） |
| 对谁求导 | $\partial L/\partial W$（链式法则把 $\hat y = Wx$ 拆开） | $\partial L/\partial \hat y$（**不拆开**，$\hat y$ 本身就是自变量） |
| $x$ 是否参与求导 | 参与（$\partial \hat y/\partial W = x$） | **完全不参与** |

为什么可以这样？因为新树直接输出一个数加到 $\hat y$ 上：$\hat y^{(t)} = \hat y^{(t-1)} + \eta f_t(x)$。我们只需要知道"每个样本的 $\hat y$ 往哪个方向挪、挪多少能让 $L$ 变小"，这正是 $-\partial L/\partial \hat y$。

## 2. 答案：先公式求导，再代数字

**第一步（纸上，一次性）**：把 $\hat y$ 当成普通变量 $x$ 对 $L$ 求导。

| 损失 | $L(y,\hat y)$ | $g = \partial L/\partial\hat y$ | $h = \partial^2 L/\partial\hat y^2$ |
|---|---|---|---|
| MSE | $\tfrac12(y-\hat y)^2$ | $\hat y - y$ | $1$ |
| LogLoss（$\hat y$ 是 logit，$p=\sigma(\hat y)$） | $-[y\log p+(1-y)\log(1-p)]$ | $p - y$ | $p(1-p)$ |

**第二步（训练时，每轮每样本）**：代入两个已知数字 $y_i$ 和 $\hat y_i^{(t-1)}$。

房价例：$y=100$，前面所有树累加的 $\hat y^{(t-1)}=70$ →
$g = 70-100 = -30$，$h=1$。就是一个普通的数。

代码里就是 `gbdt.py` 中 `grad_hess` 的一行：`return y_hat - y, np.ones_like(y_hat)`。

## 3. 为什么叫"伪"残差

- MSE：$-g = y - \hat y$ **严格等于**残差 → 拟合负梯度 = 拟合残差。
- LogLoss：$-g = y - p$，**不是** $y - \hat y$（$\hat y$ 是 logit，和 0/1 标签根本不在一个尺度）。但它作用一样：指出偏离方向和程度。

统称"负梯度"为**伪残差**。

`01_pseudo_residual/pseudo_residual.py`：公式算出的 $g=-30$ 与有限差分 $\frac{L(70+\varepsilon)-L(70-\varepsilon)}{2\varepsilon}$ 结果完全一致；并打印 LogLoss 下 $g$ 与 $y-\hat y$ 的差别。
