# 建树之前 $\hat y$ 从哪来？

> 我当时的卡点：要算 $g_i$ 得先有 $\hat y$，可我还没建树，哪来的预测？

## 答案：用的是**前面已建好的树**的累加结果，不是当前这棵

GBDT 是加法模型（接力跑）：

$$\hat y^{(0)} = \text{base score},\qquad \hat y^{(t)} = \hat y^{(t-1)} + \eta\, f_t(x)$$

- **第 0 步**：一棵树都没有，直接给常数初始值。MSE 用 $\text{mean}(y)$；LogLoss 用 $\log\frac{\bar y}{1-\bar y}$（正类比例的对数几率）。
- **第 $t$ 步**：$\hat y^{(t-1)}$ 是确定的数字 → 算 $g,h$ → 用 $g,h$ 建第 $t$ 棵树 → 加到 $\hat y$ 上 → 下一轮。

当前这棵树从不需要"先预测自己"。

## 高尔夫比喻

洞在 100 米。第 0 步球在初始位置；第 1 杆打到 70；第 2 杆前看"还差 30"再打 25 → 95；第 3 杆只补剩下的 5。每一杆都只看**当前球的位置**。
